# ثريدز وثائقي | Threads Documentary

بوابة أخبار عربية خفيفة تعرض العناوين والمقتطفات المتاحة في خلاصات RSS مع روابط المصادر الأصلية. تعمل الواجهة كموقع ثابت قابل للتثبيت على الهاتف، وتُعرض الأخبار بحسب المنطقة مع البحث والتصفية.

## النشر

يُنشر الموقع عبر GitHub Pages من هذا المستودع. الرابط المتوقع هو `https://sozanhnedy-bot.github.io/-/` بعد نجاح أول عملية نشر. لا يحتاج عرض الواجهة إلى خادم خاص أو حساب داخل الموقع.

## الأخبار والتحديثات

تُحفظ بيانات الموجز في `data/news.json`. يجلب سير GitHub Actions خلاصات RSS ويحدّث الملف عند تفعيل المتغير `AUTOMATION_ENABLED=true`. بدون مفتاح `OPENAI_API_KEY` يعرض الموقع مقتطف المصدر كما ورد في الخلاصة؛ وإذا أُضيف المفتاح، ينشئ النظام ملخصًا عربيًا موجزًا عبر واجهة OpenAI API وقد تترتب عليه رسوم.

النشر على YouTube أو X أو Facebook أو Instagram أو TikTok أو Threads غير آلي. مشغّل YouTube الرسمي يظهر داخل بطاقة الخبر فقط عند إضافة `youtube_video_id`.

## الخصوصية والتشغيل

الموقع لا يتطلب تسجيل دخول من الزائر ولا يتضمن تحليلات تتبع. لا تضع مفاتيح أو رموز وصول في هذا المستودع العام؛ أضفها فقط إلى GitHub Actions Secrets. يعتمد الموقع على GitHub Pages، وخلاصات RSS، وقد يستخدم OpenAI للتلخيص الاختياري.

## الفحص المحلي

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
node --check app.js
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.
