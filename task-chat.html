مساحة المهام

اكتب ما تريد تعديله في الموقع أو واجهات تطبيق Android بلغة عادية. سيُرسل الطلب إلى سير عمل ChatGPT في GitHub، ثم تُطبّق التغييرات المسموح بها بعد نجاح الفحوصات. ينشر الموقع تلقائيًا، أما التطبيق فيحتاج بناء APK جديدًا وإعادة تثبيته.

تنبيه خصوصية مهم

المستودع عام؛ قد تظهر مدخلات تشغيل المهام في سجل GitHub Actions. لا تكتب كلمات مرور أو مفاتيح API أو بيانات شخصية أو أي معلومة خاصة. اكتب طلبات تعديل للموقع أو واجهات التطبيق فقط.

قبل أول استخدام

أنشئ Fine-grained personal access token خاصًا بهذا المستودع وحده، واختر صلاحية Actions: Read and write فقط. لا نطلب صلاحية تعديل ملفات المستودع من الرمز الذي تدخله هنا.

يجب أن يكون مالك المشروع قد أضاف سر OPENAI_API_KEY ومتغير OPENAI_MODEL إلى إعدادات GitHub Actions. مفتاح OpenAI لا يُكتب في هذه الصفحة ولا يصل إلى المتصفح؛ وقد تُحاسب API بشكل منفصل عن اشتراك ChatGPT.
