# خطة نمو جمهور القناة العربي — استراتيجية وصول اختيارية ومتوافقة

## 1) الهدف والنطاق
بناء منظومة تساعد القناة على الوصول إلى جمهور عربي مهتم بمحتواها، مع البدء بتغطية الجمهور العربي كله بدل حصر الاستهداف في دولة واحدة. تُستخدم اللغة وموضوع الفيديو وسياق الاهتمام لتحديد أماكن النشر المناسبة، ولا يُفترض أن كل الجمهور العربي كتلة واحدة؛ تُراعى اختلافات اللهجات والتوقيتات والاهتمامات بين البلدان.

الهدف هو زيادة المشاهدات الحقيقية والاحتفاظ بالجمهور وعودة المشاهدين، وليس إجبار أي شخص على المشاهدة أو اصطناع التفاعل.

## 2) مبادئ لا يمكن تجاوزها
- لا رسائل خاصة عشوائية، ولا قوائم حسابات تُجمع من scraping، ولا إرسال جماعي غير مرغوب.
- لا بوتات للمشاهدات أو الإعجابات أو التعليقات أو الاشتراكات، ولا تشغيل تلقائي للفيديوهات بغرض تضخيم الأرقام.
- أي تنبيه مباشر يكون بعد موافقة صريحة (Opt-in)، مع إلغاء اشتراك سهل وفوري، واحترام حدود التكرار والتوقيت.
- النشر في صفحات ومجموعات ومجتمعات نملكها أو تسمح قواعدها صراحةً بالمشاركة، مع الالتزام بقواعد كل مجتمع.
- لا جمع لبيانات شخصية حساسة ولا بناء ملفات تعريف لأشخاص دون أساس مشروع وموافقة مناسبة.
- لا API مدفوع ولا اشتراك ولا فوترة تلقائية. الخدمات المجانية فقط افتراضيًا؛ وعند نفاد الحصة أو تعذر الخدمة يتوقف الجزء المتأثر بأمان.
- لا مفاتيح API أو أسرار OAuth داخل APK أو مستودع عام. أي تكامل يحتاج أسرارًا يمر عبر خادم آمن وإعدادات موثقة.
- لا نشر أو إرسال فعلي أو ربط حسابات قبل مراجعة المستخدم والموافقة الصريحة.

## 3) محرك اكتشاف الجمهور والسياق
لكل فيديو، تُحلل بياناته العامة التي يقدمها مالك القناة أو محرر مخوّل:
1. الموضوع الأساسي والموضوعات الفرعية.
2. كلمات البحث والعبارات التي قد يستخدمها الجمهور العربي.
3. اللهجة أو اللغة المناسبة: فصحى، مصرية، خليجية، شامية، مغاربية، أو صياغة عربية محايدة عند الحاجة.
4. نوع المحتوى: قصير، شرح، قصة، مقابلة، ديني، تعليمي، أو غير ذلك.
5. سياقات ومجتمعات محتملة للنشر، اعتمادًا على وصفها وقواعدها العامة، لا على استخراج قوائم أعضاء أو مراسلتهم.

يعرض المحرك اقتراحات قابلة للمراجعة البشرية، ولا يقرر وحده أن مجتمعًا ما يسمح بالنشر.

## 4) قنوات التوزيع المسموح بها
- مكتبة الفيديوهات داخل الموقع والتطبيق، مع روابط واضحة تفتح YouTube بطلب المستخدم.
- صفحات القناة وحساباتنا الرسمية، وجدولة منشورات يراجعها المحرر قبل النشر.
- مجتمعات ومنتديات تسمح قواعدها بالمشاركة، مع منشور ملائم للسياق وليس نسخًا آليًا متكررًا.
- نشرات بريدية أو إشعارات داخل التطبيق للمشتركين الذين وافقوا صراحةً.
- مشاركة المستخدم للرابط بنفسه عبر أدوات المشاركة القياسية في الهاتف.
- التعاون مع صناع محتوى أو صفحات أخرى بموافقة أصحابها واتفاق واضح.

لا يتضمن النظام إرسال رسائل مباشرة إلى غرباء أو التعليق الآلي على منشورات الآخرين.

## 5) سير العمل لكل فيديو
1. اكتشاف الفيديو من مصدر رسمي أو إدخاله يدويًا بواسطة محرر مخوّل.
2. استخراج الموضوع والكلمات المفتاحية واللغة واللهجة المقترحة.
3. إنشاء حزمة محتوى: عنوانان أو ثلاثة، وصف مختصر، منشور مناسب لكل منصة، ونص قصير لمقطع Shorts عند ملاءمته.
4. اقتراح مجتمعات أو قنوات توزيع مع إظهار سبب الاقتراح ورابط قواعد النشر إن توفر.
5. مراجعة بشرية للمحتوى والوجهة والتوقيت.
6. نشر يدوي أو عبر تكامل رسمي مصرح به فقط، وبعد موافقة المستخدم.
7. قياس النتائج الرسمية المتاحة، ثم تحسين الحزمة التالية.

## 6) نظام الموافقات والتنبيهات
- شاشة موافقة منفصلة لكل نوع تنبيه، تشرح بوضوح ما الذي سيصل للمستخدم ومعدل الإرسال.
- لا اشتراك افتراضي ولا إضافة تلقائية إلى قوائم الإرسال.
- حد تكرار قابل للضبط، ومنع تكرار التنبيه عن الفيديو نفسه.
- إلغاء الاشتراك من داخل التطبيق أو عبر رابط واضح.
- سجل موافقات وإلغاء اشتراك، مع أقل قدر لازم من البيانات.
- احترام أوقات الهدوء والمنطقة الزمنية التي يحددها المشترك.
- عند فشل خدمة الإشعارات أو انتهاء الحصة، لا ننتقل إلى مزود مدفوع تلقائيًا.

## 7) التحليلات ومؤشرات النجاح
استخدم YouTube Analytics وYouTube Data API وفق الصلاحيات والحصص والسياسات الرسمية، وبموافقة مالك القناة:
- مرات الظهور ومعدل النقر حيث تتوفر البيانات.
- المشاهدات ووقت المشاهدة ومتوسط مدة المشاهدة.
- الاحتفاظ بالجمهور ومصادر الزيارات.
- أداء الفيديوهات القصيرة والطويلة كلٌ على حدة.
- نمو المشتركين الحقيقيين، والزيارات العائدة.
- أداء الروابط والمنشورات التي نملكها، باستخدام قياس إجمالي لا يتطلب تتبع أشخاص عبر المواقع.

لا تُعرض أرقام تقديرية على أنها بيانات رسمية، ولا تُستخدم التحليلات لإرسال رسائل لأشخاص لم يوافقوا.

## 8) تجارب تحسين المحتوى
- اختبار عناوين وصور مصغرة مختلفة باستخدام أدوات YouTube الرسمية أو اختبارات تحريرية موثقة.
- مقارنة الصياغة بالفصحى واللهجات عندما يكون ذلك مناسبًا، دون تغيير مضلل لمعنى الفيديو.
- اختبار أطوال ومقدمات مختلفة لمقاطع Shorts.
- قياس النتائج على عينات وفترات كافية، وعدم استنتاج النجاح من عدد المشاهدات وحده.
- الحفاظ على الصدق: العنوان والصورة المصغرة يجب أن يعكسا محتوى الفيديو.

## 9) الأدوار والصلاحيات
- الزائر: يشاهد المكتبة ويفتح الروابط بنفسه.
- المشترك: يختار أنواع التنبيهات ويستطيع إلغاءها.
- المحرر: يقترح الحزم والوجهات ويجهز المنشورات.
- المراجع/المالك: يعتمد الوجهات والمحتوى وأي نشر أو إرسال.
- خدمة المزامنة: تقرأ البيانات المصرح بها فقط، ولا تملك صلاحية مراسلة الجمهور عشوائيًا.

تُسجل العمليات الحساسة، وتُطلب موافقة بشرية قبل أي نشر خارجي.

## 10) مراحل التنفيذ المقترحة
### المرحلة A — تخطيط ومراجعة
توثيق المنصات المسموح بها، سياسات النشر، الصلاحيات، ونموذج الموافقات. لا يوجد إرسال أو نشر آلي في هذه المرحلة.

### المرحلة B — مكتبة واكتشاف
ربط الفيديوهات العامة بالقناة، وتصنيف الموضوعات والكلمات المفتاحية، وعرض اقتراحات التوزيع داخل لوحة المحرر.

### المرحلة C — تجهيز المحتوى
توليد مسودات العناوين والأوصاف والمنشورات محليًا أو بأدوات مجانية متاحة، مع مراجعة بشرية إلزامية.

### المرحلة D — اشتراكات اختيارية
إضافة تفضيلات التنبيه وإلغاء الاشتراك وحدود التكرار، ثم اختبارها داخليًا قبل الإطلاق.

### المرحلة E — قياس وتحسين
ربط التحليلات الرسمية المصرح بها، وإظهار مؤشرات مجمعة تساعد على تحسين المحتوى.

كل مرحلة تحتاج مراجعة مستقلة قبل الانتقال إلى التنفيذ أو تفعيل أي تكامل خارجي.

## 11) شروط القبول
- لا توجد رسائل خاصة عشوائية أو آلية.
- لا توجد مشاهدات أو تفاعلات مصطنعة.
- لا يمكن إرسال تنبيه دون موافقة صريحة قابلة للإلغاء.
- كل نشر خارجي يمر بمراجعة وصلاحية واضحة.
- لا توجد خدمة مدفوعة أو ترقية أو فوترة تلقائية.
- لا توجد أسرار داخل التطبيق أو المستودع العام.
- عند انقطاع خدمة أو نفاد حصة، يفشل الجزء المتأثر بأمان ولا يعطل بقية التطبيق.
