# خطة أتمتة قناة YouTube داخل تطبيق World News (Android)

> **الهدف:** ربط فيديوهات قناتنا بالموقع والتطبيق، ومساعدة الجمهور الحقيقي على اكتشافها ومتابعتها، مع الالتزام بسياسات YouTube. هذه وثيقة تخطيط فقط؛ لا تضيف مفاتيح أو صلاحيات أو تشغيلًا تلقائيًا.

## حدّ الاستخدام المسموح

- ممنوع إنشاء حسابات أو أجهزة أو محاكيات أو بوتات لمشاهدة الفيديوهات، أو تشغيل الفيديوهات في الخلفية/التكرار لرفع المشاهدات أو وقت المشاهدة.
- ممنوع إجبار المستخدم على تشغيل فيديو أو إبقاء مشغل مخفي/صامت أو التحايل على قياسات YouTube.
- المشاهدة تتم باختيار المستخدم وبمشغل YouTube الرسمي أو تضمين YouTube المعتمد، مع ظهور عناصر التحكم بوضوح.
- لا نطلب من المستخدم الاشتراك أو الإعجاب أو التعليق مقابل خدمة أو مكافأة.
- لا نشتري مشاهدات أو تفاعلًا، ولا نستخدم خدمات تبادل الزيارات.

## الوظائف المقترحة

1. **مزامنة مكتبة القناة:** جلب بيانات الفيديوهات العامة (المعرّف، العنوان، الوصف، الصورة المصغرة، تاريخ النشر، ورابط الفيديو) عبر YouTube Data API عند تهيئة اعتماد رسمي مناسب، أو عبر مصدر عام مسموح عند تعذر ذلك. لا نسحب ملفات الفيديو ولا نعيد استضافتها.
2. **ربط الموقع بالتطبيق:** إضافة قسم «فيديوهات قناتنا» في التطبيق يقرأ قائمة الفيديوهات المنشورة من ملف بيانات عام يولده الموقع/مسار CI. كل بطاقة تفتح صفحة التفاصيل أو YouTube عند ضغط المستخدم.
3. **تنبيهات اختيارية:** إشعار واحد عند اكتشاف فيديو جديد، فقط بعد موافقة المستخدم الصريحة، مع إعدادات إيقاف/تشغيل وفترة هدوء ومنع التكرار.
4. **قوائم تشغيل تحريرية:** عرض قوائم تشغيل القناة وروابطها الرسمية، مع تصنيفها حسب الموضوع.
5. **لوحة قياس مشروعة:** عرض إحصاءات القناة التي توفرها YouTube Analytics لصاحب القناة بعد OAuth وصلاحيات المالك المناسبة. لا نحتسب مشاهدات داخل التطبيق كأنها مشاهدات YouTube.
6. **إدارة نشر اختيارية لاحقًا:** يمكن دراسة جدولة/رفع الفيديوهات عبر واجهات YouTube الرسمية وبموافقة المالك لكل عملية؛ لا تُفعّل في المرحلة الأولى.

## سياسة الوصول والصلاحيات

| الدور | ما يمكنه فعله |
|---|---|
| زائر التطبيق | مشاهدة قائمة الفيديوهات العامة وفتح YouTube يدويًا |
| مستخدم مسجل/مشترك بالتنبيهات | اختيار تلقي إشعارات الفيديوهات الجديدة وإدارتها |
| محرر محتوى | تحديث التصنيفات والروابط التحريرية دون الوصول إلى أسرار القناة |
| مالك القناة | ربط حساب Google عبر OAuth الرسمي ومنح أقل صلاحية لازمة لقراءة بيانات القناة/التحليلات |
| خدمة المزامنة | قراءة البيانات العامة فقط؛ لا تملك صلاحية مشاهدة أو تفاعل نيابة عن المستخدمين |

- لا نضع OAuth refresh tokens أو API keys الخاصة في APK أو مستودع عام أو ملفات الموقع.
- تخزّن الأسرار في GitHub Actions Secrets أو مخزن آمن خادمي، وتُمنح أقل صلاحية ممكنة.
- لا نطلب كلمة مرور Google مطلقًا؛ الربط يتم عبر شاشة موافقة Google الرسمية.
- لا نجمع بيانات شخصية غير لازمة. التنبيهات اختيارية ويمكن إلغاؤها، وتُوثق سياسة الاحتفاظ والحذف قبل الإطلاق.
- أي صلاحية جديدة أو نطاق OAuth إضافي يحتاج مراجعة وموافقة مالك القناة قبل تفعيله.

## التصميم التقني المقترح

- **Android:** شاشة قناة، قائمة فيديوهات، تفاصيل فيديو، تفضيل التنبيهات، وحالة آخر مزامنة.
- **Backend/CI:** مهمة مجدولة منخفضة التواتر تجلب بيانات الفيديوهات العامة وتنتج ملف data/youtube_videos.json بعد التحقق من الحقول والروابط وإزالة التكرار.
- **الموقع:** صفحة الفيديوهات الحالية تقرأ نفس مصدر البيانات، وتفتح الفيديو فقط بعد تفاعل المستخدم.
- **التحديث:** مزامنة دورية معتدلة مع احترام حصص API ونتائج الأخطاء؛ استخدام ETag/التخزين المؤقت حيثما أمكن.
- **الفشل الآمن:** إذا انتهت الحصة أو فشل الربط، نحتفظ بآخر قائمة صحيحة ونوقف المزامنة/التحليلات مؤقتًا دون تكرار الطلبات أو تفعيل خدمة مدفوعة تلقائيًا.

## التكلفة والقيود

- لا اشتراكات مدفوعة، ولا API مدفوع، ولا فوترة تلقائية، ولا ترقية تلقائية.
- نبدأ بالبيانات العامة والحد الأدنى من طلبات API ضمن الحصة المجانية المتاحة. يجب التحقق من الحصة الحالية قبل التنفيذ؛ لا نفترض أن أي خدمة مجانية بلا حدود.
- لا يُضاف أي مزود أو خدمة خارجية جديدة قبل موافقة صريحة من مالك المشروع.
- لا تُنفّذ مرحلة OAuth أو Analytics قبل مراجعة متطلبات Google/YouTube وسياسات المطورين السارية.

## مراحل التنفيذ ومعايير القبول

- [ ] **المرحلة 1:** تأكيد Channel ID ورابط القناة ومصدر بيانات الفيديوهات العامة.
- [ ] **المرحلة 2:** تصميم مخطط youtube_videos.json واختبارات التحقق وإزالة التكرار.
- [ ] **المرحلة 3:** ربط صفحة الموقع والتطبيق بالقائمة، مع فتح الفيديو بطلب المستخدم فقط.
- [ ] **المرحلة 4:** إضافة تنبيهات اختيارية مع إعدادات واضحة ومنع التكرار.
- [ ] **المرحلة 5:** دراسة OAuth وYouTube Analytics للمالك فقط، بعد مراجعة الصلاحيات والحصة.
- [ ] **قبل الإطلاق:** مراجعة سياسات YouTube، واختبار عدم وجود تشغيل خفي أو آلي أو تضخيم للمشاهدات، واختبار الفشل الآمن.

**حالة الوثيقة:** خطة مقترحة فقط. لم يتم تفعيل API أو OAuth أو الإشعارات، ولم يتم تعديل التطبيق أو الموقع في هذا التغيير.
