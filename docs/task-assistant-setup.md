# تشغيل Android ومهام GitHub

## APK Android

إصدار التطبيق الحالي `1.2.0` (versionCode 3) يحافظ على معرّف الحزمة `com.threadsdocumentarynews.app` ليُثبَّت كتحديث فوق النسخ الأقدم. على فرع `main`، تشغيل البناء تلقائيًا عند تعديل ملفات `android-app/`. ويمكن تشغيله يدويًا من المستودع العام `sozanhnedy-bot/-` عبر **Actions → Build Android APK → Run workflow**. عند نجاح التشغيل، افتح تفاصيله ونزّل عنصر **Threads-Documentary-News-v1.2.0-debug** من قسم Artifacts. تحتفظ GitHub بالـArtifact لمدة 90 يومًا.

البناء يحمّل نسخة sherpa-onnx الرسمية 2.0.1 ويتحقق من بصمة SHA-256 قبل بناء APK. ملف AAR لا يُحفظ داخل سجل Git، لتجنب إضافة ملف حجمه نحو 48 MB إلى تاريخ المستودع.

## المساعد المحلي داخل التطبيق

تبويب «المساعد» ينشئ مسودة سكريبت وتقسيم مشاهد على الهاتف باستخدام نموذج Qwen مفتوح المصدر. لا يحتاج هذا الجزء إلى مفتاح API. تنزيل نموذج الكتابة (~491 MB) اختياري ويبدأ فقط عندما يضغط المالك زر التنزيل. بعد تنزيله، يعمل التوليد دون اتصال.

معاينة الصوت العربي اختيارية أيضًا. اضغط زر تنزيل Nabra (~83 MB) مرة واحدة، وبعدها يمكن إنشاء الصوت وتشغيله دون اتصال. النصوص والمشاريع تحفظ محليًا في التطبيق. جودة النموذج الصغير مسودة مساعدة ويجب مراجعة الحقائق يدويًا.

## إرسال مهمة تعديل للموقع من GitHub

سير **Run owner website task** يُشغَّل يدويًا من GitHub Actions. افتح المستودع ثم **Actions → Run owner website task → Run workflow**، واكتب المهمة في حقل `task`. لا يحتاج هذا السير إلى لصق GitHub PAT داخل APK، لكنه يتطلب السر `OPENAI_API_KEY` في **Settings → Secrets and variables → Actions**.

يمكن ترك متغير `OPENAI_MODEL` فارغًا؛ الافتراضي `gpt-5.6-luna`، وهو اختيار API منخفض الكلفة نسبيًا. وإذا بقيت القيمة القديمة `gpt-3.5-turbo` أو `gpt-3.5-turbo-0125` في إعدادات المستودع، سيحولها البرنامج تلقائيًا إلى هذا البديل بدل الفشل. استخدام واجهة OpenAI API ما زال حسب الاستهلاك، ويتطلب رصيدًا/فوترة فعالة لدى مزود الحساب؛ المساعد لا يعمل مجانًا بمجرد أن اشتراك ChatGPT متاح. لا تُدرج مفاتيح أو بيانات خاصة في وصف المهمة لأن سجل المستودع وتشغيل GitHub عامان.

يُجري سير المهام اختبارات الموقع، ويتحقق من التغييرات المسموح بها، ثم يبني التطبيق ضمن اختبارات الأمان قبل اعتماد تعديل الموقع. يعتمد ذلك على تنزيل مكتبة الصوت المثبّتة ببصمتها الموثقة أثناء فحص Android.

## النشر الاجتماعي

تبويب «النشر» يجهز نصًا للمراجعة والنسخ فقط. لا يرسل التطبيق منشورات إلى X أو Facebook ولا يوجد نشر تلقائي. يحتاج النشر الحقيقي لاحقًا إلى ربط رسمي لحسابات المنصات وموافقة صريحة منفصلة؛ لا تضع مفاتيح المنصات في APK أو مستودع عام.

## حدود النسخة الحالية

APK المبني هنا نسخة `debug` موقعة للتثبيت المباشر وليست نسخة متجر. جرى التحقق من بنائه وتوقيعه محليًا، لكن اختبار تنزيل النموذج وتشغيله على هاتف المالك لم يتم من بيئة البناء. يحتاج التوليد المحلي إلى اتصال أولي لتنزيل النموذجين ومساحة تخزين كافية. يدعم بناء APK الحالي `arm64-v8a`، ويحتاج Android API 24 أو أحدث.
