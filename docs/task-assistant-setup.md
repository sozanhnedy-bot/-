# تشغيل تطبيق World News ومساعد الإنتاج

## APK Android

إصدار Android المستهدف لهذا التحديث هو `1.3.0` (versionCode 4)، مع الإبقاء على معرّف الحزمة `com.threadsdocumentarynews.app` حتى يمكن تثبيته كتحديث. بعد نجاح البناء في GitHub Actions، افتح المستودع `sozanhnedy-bot/-` ثم **Actions → Build Android APK**، واختر أحدث تشغيل ناجح ونزّل العنصر `World-News-v1.3.0-debug` من قسم Artifacts. يحتفظ GitHub بالعنصر 90 يومًا. هذا APK تجريبي موقّع للتثبيت، وليس نسخة متجر.

يتحقق سير البناء من بصمة SHA-256 لمكتبة sherpa-onnx الرسمية 2.0.1 ثم يشغّل اختبارات مسار السكريبت والصوت ويجمع APK. لا تُحفظ مكتبة AAR الكبيرة أو أوزان النماذج داخل Git.

## إنشاء مشروع فيديو نصي محلي

من تبويب «المساعد»:

1. اكتب فكرة الفيديو، وأضف — اختياريًا — حقائق أو مقتطفات تريد أن يلتزم بها النموذج.
2. اختر المنصة ونسبة العرض: TikTok/Reels أو YouTube Shorts عموديًا، أو فيديو أفقي، وحدد المدة والنبرة.
3. نزّل نموذج Qwen المفتوح (~491 MB) من داخل التطبيق مرة واحدة. بعدها يولد على الهاتف عنوانًا وفكرة وتعليقًا صوتيًا كاملًا وتقسيمًا لمشاهد مع أوصاف بصرية وأزمنة تقريبية. يحدد التطبيق عدد المشاهد وطول النص حسب المدة؛ خيار 30 ثانية لا يعامل كمدة ثلاث دقائق.
4. راجع النص والمشاهد يدويًا. النموذج يعمل محليًا ولا يتصل بالإنترنت للتحقق من الأخبار؛ لذلك يُفضّل إدخال المصادر والحقائق بنفسك ومراجعة الأسماء والأرقام قبل الاستخدام.
5. نزّل Nabra العربية المفتوحة (~83 MB) مرة واحدة. إذا كان النموذجان جاهزين، يجهز التطبيق التعليق الصوتي تلقائيًا بعد كتابة السكريبت؛ ويمكن تشغيل معاينة الصوت أو حفظ ملف WAV من نافذة حفظ Android. تصدير المشروع PDF متاح كذلك.

لا يحتاج توليد السكريبت أو الصوت المحلي إلى مفتاح OpenAI أو GitHub، ولا توجد رسوم API لكل طلب. يلزم اتصال إنترنت ومساحة تخزين للتنزيل الأولي فقط. يعمل التنفيذ بعد التنزيل دون اتصال. قد تختلف سرعة وجودة النموذج الصغير بحسب الهاتف.

**حدود مهمة:** هذه النسخة تنتج سكريبتًا ومخطط مشاهد وأوصافًا بصرية وتعليقًا صوتيًا WAV وملف PDF. لا تنشئ لقطات تصوير فعلية ولا تخرج ملف فيديو MP4 نهائيًا. إعداد فيديو مركب أو توليد لقطات مرئية يحتاج محرك فيديو/مواد مرئية إضافية غير موجودة في هذا الإصدار.

## حفظ المشروعات

يحفظ التطبيق آخر مشروع محليًا على الهاتف، بما في ذلك الفكرة والمراجع والنص والمدة والنبرة والمنصة. استخدم زر الحفظ، أو بدّل التبويب بعد وجود نص ليحفظ التطبيق تلقائيًا. لا ترفع هذه البيانات إلى موقع World News. تصدير PDF وWAV يستخدم نافذة Android لحفظ الملفات، ولا يحتاج إذن تخزين واسع.

## مهمة تعديل الموقع من التطبيق

تعديل كود موقع World News ليس هو مساعد إنتاج السكريبت المحلي. من تبويب «المشاريع» افتح نموذج المهمة في GitHub Actions، وسجّل الدخول إلى GitHub بحساب لديه صلاحية تشغيل المهام على المستودع، ثم اختر **Run workflow**. لا تلصق PAT أو مفتاح API داخل التطبيق. صلاحيات سير المهام محددة في ملفه، بينما يبقى سر `OPENAI_API_KEY` في إعدادات GitHub Actions. استخدام هذا المسار يستدعي API مدفوعًا حسب استهلاك حساب المزود، وهو منفصل عن مساعد الوسائط المحلي المجاني.

قد يظهر نص مهمة تعديل الموقع في سجل GitHub Actions للمستودع العام؛ لا تضع كلمات مرور أو مفاتيح أو بيانات شخصية في وصف المهمة.

## النشر إلى X وFacebook

تبويب «النشر» ينشئ مسودة قابلة للتحرير والنسخ فقط. لا يرسل التطبيق منشورًا ولا ينشر تلقائيًا. أي نشر فعلي يحتاج إعداد حسابات المنصات رسميًا وموافقة صريحة منفصلة، ولا ينبغي تضمين مفاتيحها داخل APK أو مستودع عام.

## متطلبات التوافق

- Android 7.0 أو أحدث (API 24+).
- جهاز `arm64-v8a` في بناء APK الحالي.
- اتصال أولي لتنزيل النموذجين، ويفضل توفر أكثر من 1 GB من المساحة والذاكرة المؤقتة أثناء التنزيل والمعالجة.
- إذن الإنترنت لتنزيل النماذج وإذن الإشعارات للأخبار على Android 13+؛ حفظ الملفات يتم عبر نافذة اختيار Android دون إذن تخزين واسع.
