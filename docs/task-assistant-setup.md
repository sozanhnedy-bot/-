# إعداد مساحة المهام داخل Android

أُزيلت واجهة المهام من صفحات الموقع. بقيت شاشة المهام داخل تطبيق Android الأصلي فقط، وأُعيد تصميمها بواجهة داكنة ولمسات ذهبية وثلاثة تبويبات: المساعد، المشاريع، والنشر الاجتماعي. تبويب المساعد يحتفظ بإرسال طلب تشغيل محدود إلى GitHub Actions، وتبويب المشاريع يفتح سجل المهام، وتبويب النشر يشرح حالة الربط ومتطلبات X/Facebook. لا يحتوي الموقع العام على حقل رمز أو زر إدارة.

## إعداد خدمة AI عند الرغبة في استخدامها

في مستودع `sozanhnedy-bot/-` افتح **Settings → Secrets and variables → Actions**. أضف السر `OPENAI_API_KEY` ومتغير `OPENAI_MODEL` فقط إذا رغبت في استخدام مساعد التعديلات. API يُحاسب منفصلًا عن اشتراك ChatGPT؛ إبقاء السر غير مضاف يوقف مهام AI ولا يوقف الموقع أو تحديث RSS.

## رمز GitHub داخل التطبيق

من GitHub افتح **Settings → Developer settings → Fine-grained personal access tokens → Generate new token**. اختر المستودع `sozanhnedy-bot/-` وحده، وصلاحية **Actions: Read and write**. لا تلصق الرمز في صفحة الموقع أو المستودع العام.

أدخل الرمز في شاشة التطبيق عند إرسال المهمة. لا يحفظ التطبيق الرمز في التخزين المحلي؛ يمسح حقل الإدخال بعد الإرسال. الرمز يمنح صلاحية تشغيل سير GitHub Actions للمستودع، فاحتفظ به خاصًا وألغِه بعد الاستخدام إذا رغبت.

## النشر الاجتماعي

يوجد مسار نشر منفصل إلى X وصفحة Facebook، لكنه مغلق افتراضيًا. عنوان البريد الإلكتروني أو كلمة مرور الحساب لا يربطان التطبيق بواجهات المنصتين. يلزم إعداد تطبيق مطوّر وصلاحيات وصول رسمية، وإضافة رموز الوصول كأسرار GitHub Actions، مع موافقة صريحة على استخدام واجهات قد تكون مدفوعة. لا تُدخل هذه الرموز في APK أو حقل مساعد المهام.

## حدود التنفيذ

تُراجع مهام الشيفرة على مسارات محددة، ثم تُختبر قبل الدمج. ملفات الأمان وسير العمل والبيانات الحساسة غير قابلة للتعديل عبر المساعد. يظهر سجل تشغيل GitHub للزوار لأن المستودع عام؛ لا ترسل أسرارًا أو بيانات شخصية في وصف المهمة. تبويب النشر يشرح المسار ولا يرسل منشورًا بنفسه. مولّد السكريبتات/المشاهد ومعاينة الصوت وتصدير PDF في الصورة المرجعية ليست وظائف قائمة في المساعد الحالي.

تغيير المصدر لا يُحدّث APK المثبت تلقائيًا؛ يلزم بناء نسخة APK جديدة وتثبيتها. يمكن فتح الموقع مباشرةً دون استخدام شاشة المهام أو إعداد أي مفاتيح.
