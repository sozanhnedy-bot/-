# تفعيل مساحة المهام

توجد مساحة المهام في صفحة الموقع وفي شاشة تطبيق Android الأصلي. كلتاهما ترسل طلب تشغيل إلى GitHub Actions؛ لا توضع مفاتيح OpenAI أو رموز GitHub داخل ملفات الصفحة أو مستودع الشيفرة.

## إعداد OpenAI

افتح إعدادات المستودع `sozanhnedy-bot/-` ثم **Settings → Secrets and variables → Actions**. أضف سرًا باسم `OPENAI_API_KEY` يحتوي مفتاح OpenAI API الخاص بمالك المشروع. أضف متغيرًا باسم `OPENAI_MODEL` بقيمة معرّف نموذج متاح في حساب API ويدعم واجهتي Responses وChat Completions. استخدام OpenAI API قد يترتب عليه تكلفة منفصلة عن اشتراك ChatGPT.

## رمز الإرسال

من GitHub افتح **Settings → Developer settings → Fine-grained personal access tokens → Generate new token**. اختر المستودع `sozanhnedy-bot/-` وحده في **Repository access**، ثم اختر **Actions: Read and write** فقط في **Repository permissions**.

أدخل الرمز عند إرسال المهمة من التطبيق أو الموقع. يرسل مباشرة إلى واجهة GitHub الرسمية لتشغيل `ai-task.yml` ثم يُمسح حقل الإدخال. لا تحفظه في التطبيق أو ملاحظة أو رسالة عامة.

## نطاق العمل والنشر

يُسمح للمساعد بتغيير واجهات ومحتوى محدد في الموقع وواجهات Android المسموح بها. لا يمكنه تعديل ملفات سير العمل أو مفاتيح الأمان أو كود إرسال المهام. يتحقق سير العمل من مسارات الملفات وأحجام التغيير والروابط الخارجية، ثم يشغّل اختبارات الموقع وبناء Android. إذا فشل فحص، لا يُحفظ التغيير ولا يُنشر الموقع.

بعد نجاح الفحوصات، تُحفظ الشيفرة في `main` ويُنشر الموقع تلقائيًا. تطبيق Android المثبت لا يستطيع استبدال ملف APK الخاص به ذاتيًا؛ يلزم بناء إصدار جديد وإعادة تثبيته يدويًا. لا تُرفع ملفات APK إلى المستودع العام لأن الجميع يستطيع الوصول إلى ملفات المستودع.

## الخصوصية

المستودع عام، وقد تظهر مدخلات تشغيل GitHub Actions للقارئين. اكتب طلبات تخص التطبيق والموقع فقط، ولا ترسل بيانات شخصية أو أسرارًا. مساعد المهام لا ينشر اجتماعيًا. النشر اليومي على X وFacebook منفصل ومغلق حتى تضبط `SOCIAL_AUTOPUBLISH=true` ورموز الحسابين؛ YouTube لا يُنشر تلقائيًا، ويحتاج موافقتك وربط OAuth مستقلًا.
