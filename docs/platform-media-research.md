# ملاحظات موثقة لتكامل الفيديو والنشر

الملاحظات التالية من وثائق المنصات الرسمية التي تمت مراجعتها في 31 أكتوبر 2026.

## YouTube داخل التقرير

يدعم YouTube تشغيل الفيديو داخل صفحة الموقع عبر `<iframe>` مع مسار `youtube.com/embed/VIDEO_ID`. يمكن استخدام نطاق `youtube-nocookie.com` لنمط الخصوصية المحسّن، وتحميل المشغل فقط بعد ضغط القارئ. بعض الفيديوهات المقيدة بالعمر لا تعمل في مشغلات المواقع الخارجية وقد تنقل المشاهد إلى YouTube، كما يجب أن يسمح صاحب الفيديو بالتضمين. بذلك يظل التقرير على الموقع، مع بقاء مشغل الفيديو تابعًا لـ YouTube.

رفع ملف إلى قناة YouTube بواسطة API يحتاج مشروع Google Cloud وتفويض OAuth 2.0 وصلاحية `youtube.upload`. لا توجد في المشروع حاليًا بيانات اعتماد Google أو موافقة OAuth، لذلك الرفع المباشر من APK غير مفعّل. المسار المتاح الآن هو رفع الفيديو لحساب المالك عبر YouTube Studio، ثم إضافة معرّفه إلى التقرير ليظهر المشغل داخل الموقع.

المصادر: [دليل مشغلات YouTube](https://developers.google.com/youtube/player_parameters)، [تعليمات تضمين الفيديوهات](https://support.google.com/youtube/answer/171780?hl=en)، و[دليل رفع الفيديو عبر YouTube Data API](https://developers.google.com/youtube/v3/guides/uploading_a_video).

## تخزين الوسائط على GitHub Pages

توصي GitHub بألا يتجاوز مستودع مصدر الموقع 1 GB، ويجب ألا يتجاوز الموقع المنشور 1 GB، وللموقع حد نطاق استخدام ناعم قدره 100 GB شهريًا. لهذا لن نخزّن ملفات الفيديو الكبيرة داخل مستودع الشيفرة؛ سنستخدم YouTube للفيديو. يمكن وضع صور تحريرية صغيرة ومضغوطة ضمن الموقع.

المصدر: [حدود GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits).

## النشر على X وFacebook

يوفر X API نقطة لإنشاء المنشورات `POST /2/tweets` ونقطة لرفع الصور `POST /2/media/upload`، ثم يُرفق معرّف الصورة بالمنشور. تعرض وثيقة X الحالية تقديرًا معلوماتيًا قدره 0.010 دولار لكل طلب رفع وسائط؛ وقد تتغير الأسعار والضرائب أو تختلف الفاتورة. كما أن الوصول إلى X API بنظام الدفع حسب الاستخدام ويتطلب حساب مطوّر ومشروعًا/تطبيقًا وتفويضًا.

توثّق Meta النشر للصفحات (Facebook Pages) بواسطة Page access token وصلاحيات مثل `pages_manage_posts`، ويجب أن يستطيع المستخدم إنشاء المحتوى على الصفحة. هذا لا يعني أن API ينشر إلى ملف شخصي عادي. نشر صور الصفحة يتم عبر API خاص بها.

تتطلب ترندات X حسب الموقع معرّف WOEID ورمز Bearer من حساب مطوّر معتمد. جعلنا معرّف الموقع إعدادًا قابلًا للتغيير؛ القيمة الافتراضية الشائعة لمصر هي 23424802، وسيتأكد نجاحها فقط عند تفعيل حساب المطوّر. عند غياب الرمز يبقى الموقع على Google Trends ولا يفشل تحديث الأخبار.

المصادر: [X إنشاء منشور](https://docs.x.com/x-api/posts/create-post)، [X رفع الوسائط وتكلفة الطلب](https://docs.x.com/x-api/media/upload-media)، [X Trends حسب WOEID ومتطلبات الحساب](https://docs.x.com/x-api/trends/trends-by-woeid/introduction)، [نظرة X API والأسعار حسب الاستخدام](https://docs.x.com/overview)، [Meta Pages API: المنشورات والصور](https://developers.facebook.com/documentation/pages-api/posts)، و[Meta Pages API: بدء الاستخدام والصلاحيات](https://developers.facebook.com/documentation/pages-api/getting-started).

## حالة التفويض والنشر

لم تُربط في المشروع حتى الآن حسابات X أو Facebook أو YouTube، ولا توجد رموز OAuth للنشر. سياسة النشر المطلوبة هي: منشور يومي على X وفيسبوك بعد ربط الحسابين رسميًا؛ أما YouTube فيجب أن يظل معلقًا حتى يصلك تنبيه وتضغط موافقة صريحة. نشر YouTube المباشر أو شاشة الموافقة داخل التطبيق لم يُنفّذا بعد؛ الربط الحالي يدعم تضمين فيديو رفعه المالك يدويًا فقط. لا تنشر أي مهمة برمجية من دردشة ChatGPT بذاتها. ترندات X اختيارية وتحتاج رمز قراءة مستقلًا، وقد ينتج عن استخدام X API رسم حسب الاستهلاك.
