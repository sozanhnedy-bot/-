# مساعد Android: الأمان والحدود

- الموقع العام للقراءة فقط ولا يحتوي نموذجًا لتشغيل شيفرة أو لوحة إدارة.
- APK الإصدار 1.2.0 لا يطلب GitHub PAT ولا يرسل طلب API لتشغيل Actions. من تبويب المشاريع يستطيع المالك فتح صفحة سير العمل على GitHub، وتسجيل الدخول هناك، ثم تشغيل مهمة الموقع يدويًا.
- سر `OPENAI_API_KEY` يبقى في GitHub Actions Secrets ولا يوضع داخل APK أو نص مهمة الموقع. القيمة القديمة لنموذج GPT-3.5 تُحوّل إلى النموذج الافتراضي الجديد داخل سير العمل؛ الاستخدام يظل معتمدًا على رصيد/فوترة واجهة OpenAI API.
- المستودع وسجلات Actions عامة. تجنب وضع كلمات مرور أو مفاتيح أو بيانات شخصية في وصف المهمة أو نتائجها.
- سكريبتات Android المحلية تستخدم ملفات النماذج المفتوحة بعد تنزيلها إلى مساحة التطبيق؛ لا ترفع نص المشروع إلى خدمة AI لهذا التوليد. يمكن للمستخدم حفظ مسودته محليًا أو تصديرها إلى PDF.
- تبويب النشر الاجتماعي يجهز نسخة نصية للمراجعة والنسخ فقط؛ لا يوجد نشر تلقائي إلى X أو Facebook في APK الحالي.
- نتائج نماذج الكتابة والصوت مسودات مساعدة وليست تقارير موثقة. راجع الحقائق والمصادر قبل استخدامها أو نشرها.
