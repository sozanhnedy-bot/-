# سياسة الربط والنشر الاجتماعي

## الوضع الحالي

تحديث الأخبار على الموقع يقرأ خلاصات RSS فقط، ولا يستدعي واجهات ترند أو شبكات اجتماعية أو خدمات تلخيص مدفوعة. لا يوجد تكامل نشر تلقائي إلى Threads أو YouTube. وتبقى الأخبار والتقارير منشورة داخل الموقع أولًا.

## Facebook وX

يوجد مسار GitHub Actions منفصل للنشر إلى Facebook وX، لكنه معطل افتراضيًا. لا يبدأ أي استدعاء خارجي ما لم يضبط المالك `SOCIAL_AUTOPUBLISH=true` و`PAID_SOCIAL_APIS_APPROVED=true` ويضف بيانات اعتماد الحسابات الرسمية. النشر مخصص لتقرير تحريري داخلي لم يُنشر سابقًا؛ ولا يستخدم موضوعات بديلة أو خلاصات RSS كمنشورات.

عند الموافقة والإعداد، يرفق X غلاف World News مع الرابط الداخلي المختصر، وتشارك صفحة Facebook رابط التقرير الداخلي ومعاينته. تبقى صورة التقرير التحريرية داخل صفحة الخبر. لا تُرسل مدخلات مساعد المهام إلى الشبكات الاجتماعية، ولا يُنشر محتوى اجتماعيًا بمجرد وصول خبر جديد.

قد تتطلب خدمات X أو Meta حساب مطور وصلاحيات وربما رسومًا. لا تُضف الأسرار إلى الملفات العامة أو التطبيق؛ تحفظ كأسرار GitHub Actions، ويجب على المالك مراجعة الأسعار والصلاحيات وسياسة كل منصة قبل تفعيل المسار. يبقى النشر مغلقًا إذا لم يوافق المالك صراحة.

## YouTube

لا ينشر النظام فيديو تلقائيًا على YouTube. يرفع المالك الفيديو عبر YouTube Studio، ويراجعه، ثم يضيف معرّفه إلى التقرير. تشغيل الفيديو داخل الموقع لا يبدأ إلا بعد ضغط القارئ. الرفع عبر YouTube Data API غير مهيأ.
